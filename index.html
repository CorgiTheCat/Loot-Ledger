Loot Ledger

Reusable DM loot presets and custom drop rates, personalized animated D20 dice, player bonuses, and shared roll history.

Created by CorgiTheCat

Install in Owlbear

View manifest

  1. Open your Owlbear profile, choose Add Extension, and paste this install link.
  2. Enable Loot Ledger in your room.
  3. As DM, select a token and choose Loot Ledger — Manage. Add drops, set rates and rarity, then begin a session.
  4. Players select the same token and choose Loot Ledger — Roll.

The DM must have the room open to resolve rolls. Every roll uses D20; a selected natural 1 awards nothing. Drops repeat without stock limits. Choose Customize dice to personalize your Built-in dice with colors, materials, five number fonts and six patterns.
